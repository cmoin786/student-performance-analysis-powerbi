# Student Performance Analysis Dashboard

## Project Overview

This project presents an interactive Power BI dashboard designed to analyze student academic performance and identify factors affecting educational outcomes.

The dashboard explores attendance, study hours, internet access, parental education, score improvement, and pass/fail rates to provide actionable educational insights.

---

## Tools Used

* Power BI
* DAX
* Power Query
* Data Modeling
* Data Visualization

---

## Business Objectives

* Monitor student performance.
* Identify factors affecting final scores.
* Analyze attendance impact on results.
* Evaluate study habits and academic outcomes.
* Compare student performance across demographic groups.
* Track pass/fail percentages.

---

## Key KPIs

* Total Students: 500
* Average Final Score: 55.98
* Pass Percentage: 64.60%
* Average Attendance: 76.38%

---

## Dashboard Features

### Student Overview

* Total Students
* Average Final Score
* Pass Percentage
* Average Attendance

### Academic Performance Analysis

* Final Score by Age Group
* Final Score by Parent Education
* Final Score by Internet Access

### Behavioral Analysis

* Study Hours vs Final Score
* Attendance vs Final Score

### Student Success Analysis

* Pass vs Fail Distribution
* Score Improvement Tracking

### Interactive Filters

* Gender
* Internet Access
* Age Group
* Pass/Fail Status

---

## Key Insights

* Students with higher study hours generally achieved better final scores.
* Internet access showed a positive impact on academic performance.
* Attendance was strongly associated with final score improvement.
* Students from different educational backgrounds displayed varying performance levels.
* Most students successfully passed the course.
